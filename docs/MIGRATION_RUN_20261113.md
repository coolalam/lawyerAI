## 后续附件及运行切换

附件清单已包含原位置参考，但实际导入用的 `path` 仍为空，偏移基准和容器格式需要确认。后续填写经核对的路径、偏移和长度后，使用 `scripts/import_attachments.py` 导入；本次未扫描、读取或复制原文件存储。其他业务附件表的原始引用随相应源表一起完整保留。

一次与独立验收同时运行的管理员 Overview 只读试验成功返回 155,689 件案件，但耗时约 144.09 秒。该测量存在并行磁盘读取影响，不作为单请求或并发容量基准；它已说明当前查询需要进一步优化和单独性能验证。因此本次没有把迁移库切换为当前运行库。

切换前仍需完成历史业务规则核对、必要的关联处理和全量查询性能验收。附件可以按本次约定后续补齐，但界面必须继续明确显示附件待导入。重复记录验收命令：

```bash
.venv/bin/python scripts/verify_migration.py \
  data/jw-db-records-20261113.sqlite3 --data-dir data --records-only
```

后端测试共 27 项通过，其中迁移相关 12 项包含缺失附件、原位置丢失、源行修改、金额汇总不符和本地快照恢复等场景。
